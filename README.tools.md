
Tools Executables Downloads
---------------------------

Here you will find packages of the executables of the tools described in the documentation.

These tools are not mandatory. They help the developer to test and process resources that will
enhance their applications.

Some tools were built using static libraries, 
some were built using dynamic libraries that will be dynamically loaded during run time.
The packages contain all the necessary files, so you do not need to install or download
the dynamic libraries packages.

In UNIX, the IupLua console needs that the LD_LIBRARY_PATH environment variable must be set
so the dynamic libraries can be loaded. For example, if you unpacked in the "/tecgraf/iup/bin/" folder:

    export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/tecgraf/iup/bin/

Available Platforms
-------------------

Here is a list of packages and some details of the platforms where they were built:

* **Linux26g4:** Ubuntu 10.04 (x86) / Kernel 2.6 / gcc 4.4 / GTK 2.20
* **Linux26g4_64:** Ubuntu 10.04 (x64) / Kernel 2.6 / gcc 4.4 / GTK 2.20
* **Linux30:** Ubuntu 11.10 (x86) / Kernel 3.0 / gcc 4.6 / GTK 2.24
* **Linux30_64:** Ubuntu 11.10 (x64) / Kernel 3.0 / gcc 4.6 / GTK 2.24
* **IRIX6465:** SGI IRIX 6.5 (mips) / gcc 3.3 / Motif 1.2
* **SunOS510:** Sun Solaris 10 (sparc) / gcc 3.4 / Motif 2.1 
* **SunOS510x86:** Sun Solaris 10 (x86) / gcc 3.4 / Motif 2.1
* **MacOS106:** Mac OS X 10.6 (x64) [Snow Leopard] / Darwin Kernel 10 / gcc 4.2 / Fink GTK 2.18
* **Win32:** Executables only for Windows NT/2000/XP/Vista/7 (generated by vc8 and vc10)
* **Win64:** Same as Win32 but for 64-bits systems using the x64 standard
* **Win32_cygw17:** Executables only for Windows NT/2000/XP, but using the Cygwin Posix system
