# System Requirements :

1. Ubuntu/Debian
2. gcc version >= 14.2.0

## Setup Commands

```
sudo apt update
sudo apt install build-essential libgtk-3-dev libx11-dev pkg-config
mkdir ./iup
mkdir ./im
tar -zxvf iup-3.32_Linux515_64_lib.tar.gz -C ./iup
tar -zxvf im-3.15_Linux515_64_lib.tar.gz -C ./im
```
